### 🚀 Featured projects

**🛒 [PriceOn](https://github.com/alyraluca/priceOnApp)**
Final Degree Project (DAM) — Android app to compare product prices across supermarkets, with barcode scanning, price-history charts, favorites, and a role-based system (guest/user/moderator/admin). Backend on Firebase (Auth + Firestore). Open source, MIT licensed.
`Java` `Android` `Firebase` `ML Kit` `MPAndroidChart`

**🥐 [Obrador](https://github.com/alyraluca/Obrador)**
ERP module built for a Business Management Systems course, extending Odoo's `product` and `mrp` models with recipes, allergens, leftovers/remainders, and reporting — plus a role-based permission system for management, kitchen staff, and sales.
`Python` `Odoo` `ERP`

**🔐 [Cybersecurity Master's notes](https://github.com/alyraluca/cibersecurity)**
Structured study guides from my Cybersecurity specialization: ethical hacking, digital forensics (Windows/Linux/mobile/cloud/IoT), incident management, security regulations (GDPR, NIS2, ENS), system hardening, and secure DevOps — each module with theory, tools, and progressive labs.
`Pentesting` `DFIR` `Hardening` `OWASP` `GRC`

**📁 [Selected Projects](https://github.com/alyraluca/selected-projects)**
A portfolio of coursework spanning object-oriented programming, concurrency, and desktop development: JDBC/JavaBeans data access, an ecosystem simulation, concurrent Python practices (threading, sockets), and a C#/WPF Minesweeper clone.
